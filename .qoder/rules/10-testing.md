# 测试规则
- 任何实现完成后，必须运行 `python -m pytest -q` 并粘贴真实输出。
- 严禁为了让测试通过而：修改断言、删除用例、加 skip/xfail、修改
  `examples/` 下的期望输出。测试与期望输出是验收基线，只有我能改。
- 新功能必须同时提交：正常用例 + 至少一个边界或异常用例。
- 测试必须固定 seed；断言"性质"（雷数、首点安全、与参考实现一致），
  不要硬编码具体盘面的字符串，除非该字符串来自 `examples/`。
- 测试文件命名 `test_<被测对象>.py`，内部按"正常 / 边界 / 异常"三节组织。
- 新增或修改测试前，先列出用例清单（输入、期望、为什么必须测），等我确认。
