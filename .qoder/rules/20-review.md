# 代码审查清单（手动触发：在 Chat 中 @rule 引用）

按以下顺序检查，每条给出「通过 / 问题 + 行号 + 建议」：
1. 分层越界：core 是否 import 了 UI；GUI 是否自行计算了游戏逻辑。
2. 信息泄露：`view()` 是否在未结束状态下暴露雷位。
3. 随机性：是否存在 `rng.py` 之外的 random 调用；seed 是否全程贯通。
4. 边界：越界坐标、1×1 棋盘、mines=0、mines=N−1、单行单列。
5. 副作用：`chord` 在旗数不匹配时是否完全无副作用。
6. 重复代码与可疑复杂度：指出具体函数与理由。
7. 是否修改了禁止修改的文件（tests/、examples/、docs/、规则文件）。
不要顺便重构；只报告问题。
