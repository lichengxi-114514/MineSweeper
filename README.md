# MineSweeper

首点绝对安全、支持纯逻辑推进提示的扫雷游戏。

> 本文件为骨架版本，将随开发进度补全。

## 目标
面向课间想用 5～10 分钟练习逻辑推理的学生，解决网页版扫雷
"首点随机踩雷"与"中高级难度被迫猜测"两个体验问题。

## 功能（计划）
- [ ] 可 seed 的棋盘生成（可复现）
- [ ] 首点安全 + 0 区自动展开
- [ ] 插旗、和弦展开、胜负判定、计时
- [ ] CLI 文本界面
- [ ] 求解器（R1 单点规则 / R2 子集差集规则）
- [ ] 逻辑推进提示
- [ ] Tkinter 图形界面

## 环境
- Python 3.10+（零第三方运行时依赖）
